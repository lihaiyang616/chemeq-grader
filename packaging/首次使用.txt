ChemEq 智批 · 首次使用
=====================

1. 把整个压缩包解压到一个普通文件夹（例如 D:\智批），不要在压缩包里直接双击。
2. 双击“启动智批.bat”。浏览器会自动打开 http://127.0.0.1:8765 。
3. 第一次打开先点“设置”：
   - 模型名：deepseek-flash
   - Base URL：https://api.deepseek.com
   - API Key：填你自己的 DeepSeek Key（老师可让技术朋友帮忙注册/充值）
   - 点“测试当前模型”，显示连接成功即可。
4. 回到“新建作业”，把标准答案逐行粘贴进去（格式：1. 2H2 + O2 --点燃--> 2H2O），创建作业。
5. 手机和电脑连同一个 Wi-Fi；打开电脑上显示的二维码/地址，拍照上传。
6. 电脑上点“复核”，检查识别结果、改分、确认；然后“导出 Excel”或“打印学情报告”。

注意：
- 只批改化学方程式题；非方程式题可以留在卷面上，不影响报告。
- AI 只负责认字；配平、电荷、条件、状态由程序判定，老师复核后才算最终成绩。
- 手写太潦草时，程序会标“待复核/无法解析”；在复核页改好转写再点“保存”即可重新判定，不用重新调 API。
- 学生姓名/学号匹配不上时，程序会要求你手动指定，不会乱记到别人名下。
- 数据都在本机 Data 目录；识别时会把压缩后的作业图片发给所配置的模型服务。
- 手机打不开时：允许 Windows 防火墙，或把电脑连到手机热点；详见“诊断.bat”。
- 如果 8765 端口被占用，程序会自动换一个端口，以启动窗口里显示的地址为准。

卸载：删除整个程序文件夹即可；学生数据在 %LOCALAPPDATA%\ChemEq\data，需要保留就先备份。
