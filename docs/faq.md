# 常见问题

## 手机打不开二维码里的地址

1. 确认手机和电脑连的是同一个 Wi-Fi（不是手机流量）。
2. 首次启动 Windows 会弹防火墙提示，点“允许访问”；没弹或点错了，双击 `诊断.bat` 看提示。
3. 学校 Wi-Fi 可能隔离设备：把电脑连到**手机热点**，再用新二维码。
4. 仍然不行：用 USB 共享网络，或看 `诊断结果.txt` 里的局域网 IP 是否和手机同网段。

## 端口 8765 被占用

程序启动时会自动往后找空闲端口，以启动窗口里显示的地址为准；也可以 `chemeq serve --port 8877`。

## API Key 测试失败

- 先点“保存并测试”（不是只填不保存）；它会先保存 Key/模型再测。
- 401/403：Key 错、模型名错、没权限，或被停用。
- 402：余额不足。
- 连接失败：公司/学校网络拦截；换网络或用代理。
- 模型名必须是 `deepseek-flash`（DeepSeek 当前视觉模型）。

## 多少钱

一页 5 题约 0.002 元；真实手写一页 12 题约 0.0036 元；40 页约 0.07–0.15 元（夜间价）。以账单为准。

## 手写字太潦草

程序会标“无法解析/待复核”。在复核页：
1. 看原图；
2. 把“学生转写”改成正确文字；
3. 点“保存第 X 题”，程序立即重判，不再调 API。

## 姓名/学号没认出来

复核页顶部“学生匹配”：从名单选，或填姓名/学号点“指定”。程序不会把没匹配上的错题记到别人名下。

## 一份作业多页

手机上传页有“怎么分”：
- 多页试卷整摞传：选“整摞上传，每 N 页算一位学生”，N 填 2；按学生顺序选照片（张三第 1、2 页，李四第 1、2 页……）。
- 只传一位学生：选“这些照片是同一位学生的多页”。
- 单页试卷：选“每张照片算一位学生”。

不要一位学生一位学生地传，整摞一次传完即可。

## 一题写了两个方程式

拆成两个题号（如 `8(1)`、`8(2)`），标准答案也拆；否则解析器会报“化学式后有多余字符”。

## 有机结构式

v0.1 只支持 condensed 式（`CH3COOH`、`C2H5OH`）。结构式/键线式会进复核；可以手写转写文本。

## 微信里打开上传页

微信内置浏览器可能限制文件选择/相机。点右上角“在浏览器打开”，或直接用 Safari/Chrome 扫码。

## Excel 打不开/乱码

用 Excel/WPS 打开 `.xlsx`。报告里的方程式是文本；如果字体缺 ↑↓，换“微软雅黑”或“Cambria Math”。

## 更新程序会丢数据吗

不会。数据在 `%LOCALAPPDATA%\ChemEq`，替换程序目录即可。更新前建议备份 `data`。

## WorkBuddy 里看不到工具

1. 完全退出并重开 WorkBuddy（不是最小化）。
2. 确认 `~/.workbuddy/mcp.json` 里有 `chemeq` 条目。
3. 版本差异：用 `install.ps1 -Uninstall` 后只装技能（L1），仍可在 WorkBuddy 里调用 `chemeq grade`。
4. 详见 [WorkBuddy 适配](../integrations/workbuddy/README.md)。
