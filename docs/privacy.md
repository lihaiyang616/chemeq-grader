# 隐私与数据

## 数据放在哪

- 程序：解压目录（便携）。
- 数据：默认 `%LOCALAPPDATA%\ChemEq`，可用 `CHEMEQ_HOME` 改。
  - `data/chemeq.db`：作业、学生、分数、转写文本
  - `data/uploads/`：压缩后的作业图片
  - `data/reports/`：导出的 Excel/HTML
  - `config.json`：模型配置、API Key、手机令牌（本机文件）

## 什么会离开这台电脑

只有**识别时压缩后的作业图片**和少量文字提示会发给你配置的模型服务（默认 DeepSeek）。除此之外：

- 不上传到本项目作者的服务器；
- 不收集遥测、不做使用统计；
- 不把图片发给 WorkBuddy 的模型（技能只传文件路径给本机 ChemEq）；
- Excel/HTML 报告只写本地。

## 模型服务商

DeepSeek/智谱等对输入数据的保留策略由服务商决定，请阅读其隐私条款。学校/家长不允许云端识别时：

1. 使用本地 Ollama 的 OpenAI 兼容地址（需要显卡，速度慢）；
2. 或只把 ChemEq 当作“转写 + 人工判分”工具，不启用自动判定。

## 学生个人信息

- 卷面姓名/学号会随图片发给模型（否则无法登记错题）。
- 本地数据库含学生姓名、学号、错题；请按学校要求保管。
- 建议：一个班批完、导出报告后，删除不需要保留的图片/作业；程序支持按作业删除。
- 仓库里的示例数据全部是合成的，不含真实师生信息。

## API Key

- 只存在本机 `config.json`；设置页只显示掩码。
- 不进日志、不进仓库；`.gitignore` 排除 `.env`/`local/`。
- 如果 Key 泄露，去服务商控制台吊销并换新。

## 删除

- 删除单个作业：会同时删除该作业的图片、提交、答案。
- 彻底删除：关闭程序，删除 `%LOCALAPPDATA%\ChemEq`。
- 卸载程序不会自动删数据；需要保留就先备份 `data`。
