# 判定规则

## 一句话

VLM 只负责把图片转成文字；判分由 `src/chemeq/core/equation.py` 和 `compare.py` 完成。

## 解析器支持

- 箭头：`→`、`-->`、`->`、`=`、`⇌`、`⇋`、`═══`（Word 压平）
- 条件：`--点燃-->`、`--MnO2,Δ-->`、`--高温-->`、`--催化剂,Δ-->`、`--通电-->`、`--光照-->`
- 条件写在等号上方：`=△=` 会自动转成 `--加热-->`
- 物种：系数（整数/小数/分数，如 `1/2`）、化学式、括号/结晶水、电荷（`Fe3+`、`SO4^2-`、`CO32-`）、状态（`(g)/(l)/(s)/(aq)`、`↑/↓`）、标注（`(浓)/(稀)/(少量)/(过量)`）
- 热化学：`ΔH = -285.8 kJ/mol`（也接受 `kJ·mol-1`）
- 氧化还原半反应：`Zn → Zn2+ + 2e-`（`e-` 作为带电粒子参与电荷守恒）

## 判分顺序

1. 无法解析 → `uncertain`（待复核）
2. 空白 → `wrong`（0 分，提醒确认）
3. 物种不一致：
   - 本身配平 → `与标准答案不同（可能合理）`，待复核
   - 不配平 → 错误
4. 物种一致但元素/电荷不守恒 → `partial`，严格模式下 0 分
5. 条件/状态/箭头/ΔH/系数不一致 → `partial`，严格模式下 0 分
6. 全部一致 → `correct`，满分

## 错误类型

`未配平`、`电荷不守恒`、`反应物错误`、`产物错误`、`条件缺失`、`条件错误`、`状态符号缺失`、`状态符号错误`、`系数未约简`、`系数错误`、`箭头类型错误`、`方程式类型不符`、`ΔH 缺失`、`ΔH 错误`、`无法解析`、`无法识别`、`与标准答案不同（可能合理）`、`未作答`。

## 多答案

同一题有多个可接受答案时，在标准答案行用 `；` 分隔：

```text
4. NaOH + HCl → NaCl + H2O；H+ + OH- → H2O | 2
```

程序会逐条比对，选最匹配的一条。

## 严格评分

老师要求“只要出错都不给分”：

- `partial` 的判定保留（用于统计错因），但分数是 **0**。
- 如果以后想给部分分，把 `strict_scoring` 设为 false（设置页勾选“严格评分”对应 true）。

## 为什么不用 LLM 判分

- 配平/电荷是可计算事实，不是语言问题。
- LLM 会把“看起来合理”的系数说成对的；解析器不会。
- 老师改完转写后可以立即重判，不需要再调模型。

## 已知不支持的写法

- 有机结构式、键线式、复杂络合物
- 一题多个方程式（请拆题号）
- 热化学的盖斯定律计算（只比对方程式的 ΔH，不做计算）
- 非方程式题（填空、选择、简答）
